## Status: Fixed bugs

These were found in the initial audit and have been resolved.

| # | Was | Fix |
|---|-----|-----|
| 1 | `TKRetrievePipeline` no pagination — `limit=100` hard cap silently dropped records | `top=0` always passed to OData; `limit` now an opt-in dev cap with WARNING log |
| 2 | Stemmingen `Besluit_Id` null → all group under key `""` → data corruption | Records with no `Besluit_Id` are skipped at grouping time |
| 3 | Dossiers with same `nummer` but different `toevoeging` overwrote each other | `nodes` dict now keyed by `"{nummer}-{toevoeging}"` when toevoeging is present |
| 4 | Missing `RELATION_LID_VAN`, `RELATION_BEHANDELD_DOOR`, `RELATION_GEDAAN_IN` constants | Added to `config/settings.py`; all hardcoded strings replaced |
| 5 | CORS origins hardcoded to localhost | Moved to `LAWGRAPH_ALLOWED_ORIGINS` env var |
| 6 | 3 stale pyproject.toml entry points producing `ModuleNotFoundError` | Removed |
| 7 | 7 implemented CLI modules not registered as entry points | Registered |
| 8 | `retrieve-all` / `normalize-all` didn't include TK dossier pipelines | Added with skip-env-var guard |
| 9 | `print("Done.")` in `normalize_tk_dossiers.py` bypassed structured logging | Replaced with `logger.info()` |
| 10 | Missing indexes: `edges.confidence`, `edge_status_log.timestamp/edge_key` | Added to `_ensure_indexes()` |
| 11 | Missing `(source, kind)` index on `raw_sources` → full-collection scan on normalize | Added; fixes normalize timeout on large datasets |
| 12 | No `/api/health` endpoint | Added at `GET /api/health` with ArangoDB connectivity check |
| 13 | `/api/publications` had no pagination | Added `limit` / `offset` query params (default: 50, max: 500) |
| 14 | `order` param on dossier routes accepted any string | Changed to `Literal["asc", "desc"]` |
| 15 | English/Dutch mixed 404 messages | Standardised to English across all route files |
| 16 | `add_watch` accepted any `node_id` without validation | Now validates format, collection existence, and document existence |
| 17 | No HTTP retry in `BaseClient` | Added `_get_raw_with_retry()` with exponential backoff (factor 2, 3 retries) on 429/503/Timeout |
| 18 | `load_dotenv()` called on every `BaseClient.__init__()` | Moved to module level |
| 19 | TK semantic detector silently missed article stubs | Stub nodes created for high-confidence (≥0.85) misses |
| 20 | EU semantic detector same gap | Same fix applied |
| 21 | CELEX regex in instrument_relations missing `F` and `C` types | Fixed: `[CLRDF]` |
| 22 | `ArangoClient` used default 60 s timeout → normalize runs timed out | `request_timeout=620` |
| 23 | All retrieve/normalize/semantic CLIs missing `sys.exit(1)` — CI/CD couldn't detect failures | Added `sys.exit(1)` after error logging in all 12+ CLIs |
| 24 | `main()` signatures inconsistent — some CLIs didn't accept `argv` (untestable) | All CLIs now accept `argv: list[str] \| None = None`; pass it to `parser.parse_args()` |
| 25 | Dutch log messages in `normalize/bwb.py` mixed with English elsewhere | All 10 Dutch log strings translated to English |
| 26 | `TkNormalizePipeline` never wrote `kamerstuknummer` to procedure nodes — `DEEL_VAN_DOSSIER` procedure→dossier edges were never created | `kamerstuknummer` now extracted from `Nummer`/`ZaakNummer` and stored; cross-link edges now built on next normalize run |
| 27 | OData expand fields assumed to be lists — silent failure if API returns unexpected shape | `isinstance` guards added in `_normalize_activiteiten`, `_enrich_dossier_fasen`, `_normalize_stemmingen` |
| 28 | `Lid.partij` always empty string for independent MPs | Now defaults to `"onafhankelijk"` when `Fractielabel` is absent or empty |
| 29 | `Toezegging→Dossier` edge never built despite `dossier_id` being stored | `_link_toezeggingen` now creates `DEEL_VAN_DOSSIER` edge via `_find_dossier_by_external_id` |
| 30 | CommissieZetel date ranges ignored — `LID_VAN` edges were timeless snapshots | `geldig_van`/`geldig_tot` now stored as `meta` on `LID_VAN` edges |
| 31 | `rs-index` records fetched but never produced nodes — no automatic ECLI discovery | Index records now create lightweight stub nodes (`["Rechtspraak", "Stub"]`) in `judgments` |
| 32 | `TkNormalizePipeline.domain_profile` hardcoded to `"strafrecht"` | Constructor now accepts `domain_profile: str = "strafrecht"`; CLI exposes `--profile` |
| 33 | TK, EU, BWB semantic pipelines ignored `since` — always did full scan | All three now filter `raw_sources` by `fetched_at >= since` and load only matching nodes |
| 34 | CORS still hardcoded in `api/app.py` | Moved to `LAWGRAPH_ALLOWED_ORIGINS` env var |
| 35 | No request latency logging on API | Added HTTP middleware logging method, path, status, and duration |
| 36 | No startup warning for missing env vars | `_validate_env` startup handler warns on missing `ARANGO_URL`, `ARANGO_PASSWORD`, `LAWGRAPH_ALLOWED_ORIGINS` |
| 37 | No structured JSON logging option | `LAWGRAPH_LOG_FORMAT=json` now installs `_JsonFormatter` producing one JSON object per log line |
| 38 | No `Fractie` (party) nodes — party name stored as plain string in stemmingen | `NodeType.FRACTIE`, `COLLECTION_FRACTIES`, `_normalize_fracties()` added; `LID_VAN_FRACTIE` edges built from `Lid.partij` |
| 39 | Mixed-type dossiers discarded Zaak type info | `_enrich_dossier_fasen` now stores `zaak_soorten` list on dossier props alongside `huidige_fase` |
| 40 | BWB instrument title always stub `"BWB-regeling {id}"` | `_extract_instrument_title()` now parses `citeertitel`/`officiele-titel`/`intitule` from toestand XML |
| 41 | EUR-Lex article number cap hardcoded at 200 | `_EU_MAX_ARTICLE_NUMBER` now reads `EURLEX_MAX_ARTICLE_NUMBER` env var (default 200) |
| 42 | Zero test coverage for parliamentary routes | Added `tests/api/test_parliamentary_api.py` with 6 passing tests for dossiers, commissies, stemmingen |
| 43 | `@app.on_event("startup")` deprecation warning | Replaced with `lifespan` context manager |
| 44 | No input format validation on route path params | `Path(pattern=...)` added for `bwb_id` (`^BWB[RrVv]\d{7}$`), `ecli` (`^ECLI:[A-Z]{2}:...`), `kamerstuknummer` (`^\d+(-[A-Z]+)?$`); invalid inputs return 422 |
| 45 | No rate limiting on API | Sliding-window `_RateLimitMiddleware` added (200 req/60 s per IP); configurable via `LAWGRAPH_RATE_LIMIT_CALLS` / `LAWGRAPH_RATE_LIMIT_PERIOD`; returns 429 + `Retry-After` |
| 46 | No `Cache-Control` headers on stable GET responses | `_CacheControlMiddleware` added; articles 30 min, judgments 1 h, stats 5 min, everything else 60 s private |
| 47 | Test ECLI fixtures didn't include `ECLI:` prefix — broken by route validation | `test_judgments_api.py` updated to use `ECLI:NL:HR:2020:123`; `test_nodes_api.py` updated to use `NodeGraphData(neighbors=[...])` constructor |
| 48 | EU C-category (`Besluit`) and D-category (`Kaderbesluit`) CELEX codes never matched in `tk_articles.py` | Added `_ARTICLE_BESLUIT_PATTERN` (→ `C`) and `_ARTICLE_KADERBESLUIT_PATTERN` (→ `D`); `format_celex` in `citation_detect.py` extended to all four kinds |
| 49 | Document text truncation at 200 KB was silent | Debug log emitted in `_extract_document_text` when `_MAX_TEXT_LENGTH` is hit |
| 50 | `rechtspraak_articles.py` bare-article confidence 0.35 lacked explanatory comment | Inline comment added: intentionally below 0.85 stub threshold to prevent ambiguous stubs |
| 51 | Rechtspraak `props.summary` never scanned for ECLIs | `_extract_judgment_text` now joins `raw_xml`, `text`, and `summary` before detection |
| 52 | No "reason" label on semantic edges — opaque graph traversal | `_hit_reason()` helper added to `citation_detect.py`; `meta.reason` field populated on all TK, EU, and Rechtspraak edges |
| 53 | No legislative amendment text scanner | `amendment_articles.py` pipeline added; detects five Dutch amendment patterns; creates `WIJZIGT`/`INTRODUCEERT`/`TREKT_IN` edges; registered as `lawgraph-semantic-amendment-articles` and included in `semantic-all` |
| 54 | No per-pattern confidence calibration without code changes | `get_confidence_override(pattern_name, default)` added to `settings.py`; reads `LAWGRAPH_CONFIDENCE_<PATTERN_NAME>` env vars |
| 55 | No regex pattern test suite | `tests/semantic/test_regex_patterns.py` added: 51 tests covering all amendment patterns and `format_celex` for all four CELEX kinds |
